<p align="center">

A modern, fully responsive, multi-category e-commerce website built from scratch using HTML5, CSS3, and vanilla JavaScript. It delivers a seamless online shopping experience with 390+ products, live search, shopping cart, wishlist, responsive layouts, and production-ready SEO, performance, and accessibility optimizations.

## ✨ Features

- 🛍️ Browse **390+ products** across **40+ product categories**
- 📂 Responsive product catalogue with intuitive category navigation
- 🛒 Shopping cart with quantity management and persistent storage using `localStorage`
- ❤️ Wishlist functionality with persistent state using `localStorage`
- 🔍 Live product search with instant filtering and quick product discovery
- 📄 Dedicated product detail pages with quantity selection before adding items to the cart
- 🏷️ Featured products, promotional banners, and special deals section
- 🎨 Modern, clean, and user-friendly interface with intuitive navigation
- 📱 Fully responsive design optimized for mobile, tablet, laptop, and desktop devices
- ⚡ Fast and optimized browsing experience with lazy-loaded and compressed images
- 🚀 SEO optimized with Meta Tags, Open Graph Tags, JSON-LD, `sitemap.xml`, and `robots.txt`
- 📦 Progressive Web App (PWA) support via `manifest.json`
- ♿ Accessibility-friendly with semantic HTML5, ARIA labels, keyboard navigation, skip-to-content support, and visible focus states
- 📑 Multi-page website architecture with well-organized product categories
- 🧩 Clean, modular, scalable, and maintainable project architecture
- 🌍 Cross-browser compatibility across all major modern web browsers
- 📁 Optimized asset organization for improved maintainability and performance
- 🚧 Custom 404 Error page for invalid routes

## 🚀 Installation

Follow these steps to set up and run the project locally.

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/ahmad-raza-khan9121/fly-bazaar.git
```

### 2️⃣ Navigate to the Project Directory

```bash
cd fly-bazaar
```

### 3️⃣ Launch the Application

Open the **index.html** file in your preferred web browser.

> **Note:** 💡 This project is built using pure HTML, CSS, and JavaScript. No package manager, build tools, or additional dependencies are required.
